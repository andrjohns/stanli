# stanrt M2 (compiler) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compile any supported `.stan` file to a stanrt op graph via the vendored stanc3 binary's `--debug-transformed-mir` s-expression output, load JSON data, and sample it, with gradients differentially tested against references; grow corpus coverage measured on posteriordb.

**Architecture:** stanc3 (vendored release binary, pinned ac69570) emits transformed MIR as sexp. A C++ "graph compiler" inside stanrt parses the sexp, lowers the log_prob block to the op graph (parameter reads with constraint transforms + jacobian accumulation, expression lowering to elementwise/density ops), and binds the prepare_data block against JSON data. No OCaml toolchain anywhere; no C++ toolchain on user machines.

**Tech Stack:** C++17, vendored nlohmann/json single header (pinned), existing M1 runtime, stan-math for references, posteriordb for corpus.

## Global Constraints

- All M1 constraints hold (fp-contract off, no stan-math edits, bitwise-or-bounded test policy, commit per green cycle, no AI attribution, no em-dashes).
- propto policy: stanc3 emits FnLpdf true for `~` statements; M2 lowers ALL densities to the existing propto=false kernels. Gradients must match references exactly; lp may differ from CmdStan by a per-model constant. Tests verify the constant is constant across parameter points.
- MIR input is always `--debug-transformed-mir` (has FnReadParam + constrain), never plain `--debug-mir`.
- Unsupported constructs must fail compilation with a clear message naming the construct, never miscompile.

### Task 2: MIR model + reader

```cpp
namespace stanrt::mir {
struct Expr {
  enum Kind { Var, LitInt, LitReal, FunApp, Promotion, Indexed } kind;
  std::string name;            // Var name or function name
  enum class Lib { StanLib, Internal, UserDefined } fn_lib;
  bool fn_propto = false;      // FnLpdf true / FnLpmf true
  double lit = 0; long lit_i = 0;
  std::vector<Expr> args;      // FunApp args, Promotion inner, Indexed base+indices
  std::string type_;           // UInt/UReal/UVector/URowVector/UMatrix/UArray...
  bool data_only = false;      // adlevel
};
struct Transform {             // constrain spec on FnReadParam
  enum Kind { Identity, Lower, Upper, LowerUpper, Offset, Multiplier,
              OffsetMultiplier, Unsupported } kind;
  std::vector<Expr> args;
  std::string raw;             // for Unsupported error text
};
struct Stmt {
  enum Kind { Decl, Assignment, TargetPE, Block, SList, For, IfElse, NRFunApp,
              Skip, Unsupported } kind;
  // Decl:
  std::string decl_id; struct SizedType { std::string base; std::vector<Expr> dims; } decl_type;
  bool has_init = false; Expr init;            // FnReadParam lands here
  std::optional<Transform> read_transform;     // set iff init is FnReadParam
  // Assignment: lhs var (+ optional indices), rhs
  std::string lhs; std::vector<Expr> lhs_idx; Expr rhs;
  // TargetPE:
  Expr target;
  // For: loopvar, lower, upper, body
  std::string loopvar; Expr lower, upper;
  std::vector<Stmt> body;                      // Block/SList/For body; IfElse then+else
  Expr cond;                                   // IfElse
  std::string raw;                             // Unsupported error text
};
struct Program {
  std::vector<std::pair<std::string, SizedType>> input_vars;   // data decls
  std::vector<Stmt> prepare_data;
  std::vector<Stmt> log_prob;
};
Program read_program(const sexp::Node& root);  // throws on malformed
}
```

### Task 3: Constraint transform ops

**Files:** Modify `runtime/include/stanrt/optable.hpp`, `runtime/kernels/elementwise.cpp`; create `tests/test_transforms.cpp`.

**Interfaces:** new opcodes, each `(raw_slot, [bound args...]) -> constrained_slot`, PLUS accumulating their log-jacobian into a dedicated scalar slot passed as the last input:
- `OP_CONSTRAIN_LOWER`: out[i] = lb + exp(x[i]); jac += x[i]
- `OP_CONSTRAIN_UPPER`: out[i] = ub - exp(x[i]); jac += x[i]
- `OP_CONSTRAIN_LU`: out[i] = lb + (ub-lb)*inv_logit(x[i]); jac += log(ub-lb) + log_inv_logit(x[i]) + log1m_inv_logit(x[i])
Backward: hand vjps, accumulation order matching stan-math's read_constrain_* var path (element order descending where summed; verified by test).
The jac slot is an ordinary op input/output: `OP_CONSTRAIN_*` reads jac, writes jac' (functional style: jac_out slot per op, threaded by the lowering).

- [ ] Test: each transform, scalar and vector, value+jacobian+gradient vs `stan::math::lb_constrain<true>(x, lb, lp)` etc. on var (bitwise; the constrain functions are simple enough). RED, implement, GREEN, commit.

### Task 4: Generic elementwise expression ops

**Files:** Modify `runtime/include/stanrt/optable.hpp`; create `runtime/kernels/eltwise_expr.cpp`, `tests/test_eltwise.cpp`.

**Interfaces:**
- Binary with broadcast, idata={} : `OP_ADD`, `OP_SUB`, `OP_MUL`, `OP_DIV`, `OP_POW` over (scalar|vector)x(scalar|vector) by runtime len (len==1 broadcasts). Hand vjps with tape-order accumulation (descending loops, direct accumulation).
- Unary elementwise: `OP_NEG`, `OP_EXPV` (vector exp), `OP_LOGV`, `OP_INV_LOGIT`, `OP_SQRT`, `OP_SQUARE`, `OP_LOG1M`. Vjps in doubles.
- `OP_SUM_VEC` (vector -> scalar, ascending sum matching Eigen redux), `OP_DOT` (two vectors).
StanLib name -> opcode map lives with the lowering (Task 5), not here.

### Task 5: Lowering (the graph compiler)

**Files:** Create `runtime/include/stanrt/compile.hpp`, `runtime/src/lower.cpp`, `tests/test_lower.cpp`.

**Interfaces:**
```cpp
namespace stanrt {
struct CompiledModel {
  Graph graph;
  // name -> slot for data binding; sizes may reference data scalars, so
  // sizing happens at bind time:
  struct DataVar { std::string name; mir::SizedType type; int slot; };
  std::vector<DataVar> data_vars;
  std::vector<std::string> param_names;   // declaration order, unconstrained
  int64_t n_unconstrained;                // known after bind_data
};
// Lower transformed-MIR text. Data sizes resolved against `data` (JSON-like
// map name->double/int/vector) BEFORE graph finalization: M2 sizes the graph
// concretely per dataset (symbolic shapes deferred).
CompiledModel compile_model(const std::string& tmir_sexp,
                            const class DataMap& data);
}
```
Lowering rules (log_prob):
- Decl w/ FnReadParam: allocate param slot (len from dims resolved against data), then constraint op if not Identity (jac threading: running jac slot chain, seeded by a zero const slot); constrained result becomes the variable's slot.
- Decl w/o init: allocate intermediate slot on first assignment.
- Assignment (whole-variable, no indices in M2): lower rhs expression tree bottom-up; expression lowering returns a slot; Var refs resolve through a scope map; Lit/Promotion(Lit) become const data slots (deduplicated).
- FunApp StanLib arithmetic (Plus__ etc.) -> Task 4 ops by arity/shape; `foo_lpdf/_lpmf` -> density opcodes via a registry keyed by MIR name (normal_lpdf, cauchy_lpdf, student_t_lpdf, gamma_lpdf, beta_lpdf, poisson_log_lpmf, bernoulli_logit_lpmf to start + Task 9 growth); integer-array outcomes route through idata (constant) or int data slots.
- TargetPE(e): lower e, chain into target accumulator via OP_ADD_N at the end (collect terms, single final ADD_N including all jac slots).
- Block/SList: recurse. For/IfElse/Indexed/While: compile error "unsupported in M2 tier-1" (Task 9 lifts For+Indexed).
- prepare_data: Decl -> data slot registered in data_vars; FnCheck Lower/Upper -> load-time validation; FnValidateSize -> size check.
Unsupported anything -> `CompileError` with the construct's raw sexp.

### Task 9: Corpus expansion loop (ongoing)

**Files:** Create `tools/corpus.py` (drives: stanc over posteriordb model, compile attempt, classify failure by missing construct/function), `tests/test_corpus.cpp` (parameterized over a checked-in list of passing models + their reference fixtures), scoreboard in `docs/corpus-status.md`.

Loop, priority-ordered by the survey (scratchpad m2/survey/RESULTS.md):
1. Run corpus.py -> failure histogram by missing feature.
2. Pick highest-count missing feature; add it (new density kernel via the Task 4/5 registries, For-loop lowering via unroll when bounds are data, Indexed with Single/All when index data-only, matrix types, remaining transforms per survey).
3. Each addition lands with its own differential test vs a var reference; each newly passing model gets gradient reference checks (make_reference.py) before entering test_corpus.
4. Update scoreboard; commit; repeat until >60 of 120 posteriordb models compile and pass gradient checks (M2 exit), then continue as capacity allows.
